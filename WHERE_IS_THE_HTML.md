# Where the HTML lives

The Ed Salah HTML shell is:

- `static/index.html`

The working FastAPI pages are generated by `render_index()` inside:

- `app.py`

Design and frontend behavior are in:

- `static/index.css`
- `static/index.js`

For Render, the service starts through `render_app.py`, which imports the same FastAPI `app` and adds family password protection plus `/health`.
